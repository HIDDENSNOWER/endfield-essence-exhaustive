# Endfield-Essence-Exhaustive

**EEE · 终末地基质穷举数据记录与统计工具**

> 为《明日方舟：终末地》设计的**纯前端单页工具**，用于记录、管理、统计"基质"数据。
> 零构建、零依赖、零后端 —— 一个文件夹拷贝走即可用。

**当前版本**：v0.9.1

---

## 快速开始

本项目通过 `fetch` 异步加载默认数据集与图片，**`file://` 协议会被浏览器拦截**，因此需要本地 HTTP 服务器：

**推荐方式** — 双击根目录的 `一键本地运行.bat`，脚本会自动用 Python 或 Node 启动服务器并打开浏览器。

**手动方式** — 任选其一：

```bash
python -m http.server 8000
npx http-server -p 8000
```

然后访问 <http://localhost:8000>。

> 不需要安装依赖、不需要构建、不需要数据库。
> 数据集与设置保存在 `localStorage`，图片保存在 `IndexedDB`。

## 能做什么

### 📊 数据记录
- **840 格数据矩阵**：12 个提升项 × 14 词条组 × 5 主属性
- **三种记录方式**：数值输入、实装基质录入、撤减/清除
- **数值智能对比**：输入新数值时给出"保留 / 替换"建议，附计算依据

### 🗂 多数据集管理
- 新建、重命名、删除、切换数据集
- 数据集级备注（最长 550 字）
- **数据集覆盖 / 合并**：勾选多个数据集，冲突逐格处理，结果实时预览

### 📝 备注系统
- 单元格备注文本 + 图片（单格 ≤ 10 张，每张 ≤ 1 MB）
- 悬浮框支持拖拽、缩放、三种布局
- 应用内大图查看器（滚轮缩放）

### 🎯 未获取基质统计（v0.9.1 新增）
- **全局排名**：按刷取组合（3 主属性 + 1 副属性/词条）统计缺口，取前 36 名
- **进度条**：每条显示完成度（红 <30% / 橙 30~70% / 绿 ≥70%）
- **地区筛选**：可只看关注地区，筛选状态持久化
- **双色高亮**：鼠标悬停条目 → 未获取格红框、已获取格绿框，自动定位
- **变暗蒙版**：非高亮格自动弱化，聚焦视觉
- **缺口计数**：`t>0 且 a<t` 计 `(t-a)`，完全空白计 `1`

### 🗺️ 地区管理（v0.9.1 新增）
- 内置 12 个地区（枢纽区、源石研究园、矿脉源区……）
- 每个地区配置：8 个可获取副属性 + 8 个可获取词条
- 支持新增 / 编辑 / 删除 / 恢复默认
- **悬停高亮**：鼠标悬停地区卡片 → 表格中该地区 320 格可刷基质同步高亮

### 💡 可获取地点悬浮窗（v0.9.1 新增）
- 悬停未获取单元格 → 显示所有可获取该基质的地区
- 每个地区列出两条刷取路径（选副属性 / 选词条）
- **跟随筛选**：优先显示未获取统计面板中勾选的地区
- **无结果回退**：筛选下无可获取地区时，显示提示并列出全部
- **与备注并列**：不覆盖、不互斥，位置自动错开

### 🎨 个性化
- **明暗主题**：跟随系统或手动切换，无闪烁
- **单元格状态颜色**：已拥有 / 未获取 / 部分获取 / 全部获取
- **界面颜色**：所有 CSS 颜色变量均可调，含完整主界面预览
- **方案管理**：界面方案与单元格方案独立保存、导入导出

### 💾 数据安全
- **导入导出**：ZIP（含图片）或 JSON，重名冲突时可选覆盖/合并/另存
- **默认数据集保护**：只增不减，刷新不覆盖用户修改
- **存储管理**：查看配额、明细、每个数据集的占用
- **清除缓存**：清除前展示已保存的全部内容清单，清理 localStorage + IndexedDB

## 数据模型

每个单元格是一个对象：

| 字段 | 含义 | 约束 |
|------|------|------|
| `v` | 数值（普通数值或实装属性值） | 空串 = 无数值 |
| `t` | 重复数（实装基质重复次数） | ≥ 0 |
| `a` | 已获取数 | `0 ≤ a ≤ t`（自动夹紧） |
| `note` | `{ text, images[] }` | images 为 IndexedDB 图片 ID |

**单元格状态**由 `t` / `a` 决定：

- `t=0` 且 `v≠''` → **has-value**（仅数值）
- `t>0, a=0` → **未获取**
- `0 < a < t` → **部分获取**
- `a = t` → **全部获取**

**表格结构**：14 词条组 × 5 主属性 = 70 列，分两段渲染（强攻~残暴 / 附术~效益）。

**刷取机制**：每个地区提供 8 副属性 + 8 词条，每次刷取选择 3 主属性 + 1 副属性或 1 词条，从 24 种候选中随机获得 3 个。

## 常见问题

### ❓ 打开后数据没加载？

**必须通过 HTTP 服务器访问**，不能直接双击 `index.html`（`file://` 下 `fetch` 被跨源策略拦截）。使用 `一键本地运行.bat`。

### ❓ 我的数据存在哪里？

- **数据集、设置、备注文本、地区配置**：浏览器 `localStorage`
- **备注图片**：浏览器 `IndexedDB`（数据库 `eee_image_db`）
- **会话标记**：`sessionStorage`

同一浏览器的数据按 **origin** 隔离，`localhost:8000` 与 `localhost:3000` 的数据**不互通**。

### ❓ 换电脑 / 换浏览器怎么迁移数据？

使用「导出」功能生成 ZIP（推荐，含图片），在新环境「导入」即可。JSON 导出**不含图片二进制**，仅适合纯数据迁移。

> **注意**：地区配置、地区筛选设置目前不随数据集导出，需在新环境重新配置。

### ❓ 默认数据集被我改乱了？

点「重置同步」按钮，会重新从 `data/data.json` 拉取初始数据。**注意**：重置后用户添加的数据会丢失。

### ❓ 数据丢失了怎么办？

工具本身不做云端备份。建议：
- 定期用「导出」保存 ZIP 备份
- 避免使用浏览器"清除浏览数据"功能
- 使用「清除缓存」按钮时，弹窗会展示将删除的内容清单

### ❓ 图片显示不出来？

- 检查 `data/images/` 目录下图片文件是否存在
- 若使用 JSON 导入，图片 ID 无法还原为实际图片，需改用 ZIP

### ❓ 未获取统计中的数字怎么算的？

每个刷取组合对应 24 格（3 主属性 × 8 副属性/词条）。每格的"缺口贡献"：

| 单元格状态 | 贡献 |
|-----------|------|
| `v='', t=0`（完全空白） | +1 |
| `v≠'', t=0`（仅数值） | 0 |
| `t>0, a=t`（刷满） | 0 |
| `t>0, a<t`（未刷满） | `t - a` |

累加 24 格贡献 = 该组合的"未获取"值。

### ❓ 地区悬停高亮为什么没反应？

- 检查该地区是否配置了副属性和词条（至少各 1 个）
- 检查表格中是否有对应单元格（可能被行筛选隐藏）
- 检查是否在未获取统计面板有激活的鼠标悬停状态（可能互相清除）

## 技术特性

- **模块化**：IIFE + 全局 `App` 命名空间，无构建工具
- **分层清晰**：核心层 → 服务层 → 功能层 → 入口层
- **XSS 防护**：所有用户输入在拼入 `innerHTML` 前统一转义
- **存储隔离**：图片存 IndexedDB，与 localStorage 分离，降低配额压力
- **容错设计**：`normalizeCell` 自动夹紧 `a ≤ t`，颜色越界钳制，回调关闭即清理
- **竞态防护**：异步加载默认数据前记录数据集键，防止切换后写入错误位置
