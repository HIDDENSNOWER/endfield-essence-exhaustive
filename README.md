# Endfield-Essence-Exhaustive (EEE)

**终末地基质穷举数据记录与统计工具**  
Ver.0.5.1 ("再访基地"更新)

一个用于记录、管理和统计《终末地》中"基质"数据的纯前端工具。  
支持多数据集管理、数据导入导出、备注与图片、颜色个性化、明暗主题等功能。

## 文件与文件夹详细说明

### `index.html`

- 应用主页面，包含所有 UI 结构（导航栏、表格区、侧边栏、面板、弹窗等）。
- 按顺序引入拆分后的 CSS 和 JS 文件。
- 所有元素均带有唯一的 `id`，供 JavaScript 模块缓存和操作。

### `css/` 样式表

| 文件 | 用途 |
|------|------|
| `base.css` | 定义全局 CSS 变量（颜色、尺寸、字体等），包含亮色/暗色两套主题变量；提供全局重置样式、字体、滚动条等基础样式。 |
| `layout.css` | 管理页面整体布局：导航栏、主布局、表格区、侧边栏、面板容器、底部信息栏、响应式调整及右侧面板折叠系统。 |
| `components.css` | 通用 UI 组件样式：按钮系统（多种类型）、表单元素、弹窗、统计卡片、行筛选、单元格悬停提示栏、Toast 提示、版本信息弹窗等。 |
| `features.css` | 特定功能样式：备注显示与编辑、图片上传、备注悬浮框（拖拽/调整/布局切换）、图片查看器、默认数据集加载指示器等。 |
| `settings.css` | 设置弹窗及内部布局：设置导航、颜色预览表格、颜色编辑面板、移动端适配等。 |

### `js/` 脚本

#### `js/lib/` 外部库

- `jszip.min.js`：用于导出/导入 ZIP 文件，将数据与图片打包或解包。

#### `js/core/` 核心层

- `constants.js`：集中定义所有常量，包括存储键名、词条组与行名、颜色变量、默认尺寸等，避免硬编码。
- `state.js`：管理全局状态（行数据、主题、当前面板、历史记录、筛选行等）及其他全局可变变量（定时器、回调、基准数据等），通过 getter/setter 安全访问。
- `dom.js`：在 DOM 加载完成后一次性缓存所有需要的元素引用到 `App.dom` 对象，避免重复查询。
- `utils.js`：提供纯函数和轻量 DOM 辅助函数，如单元格标准化、数字解析、列索引计算、颜色转换、图片格式转换等。
- `data-model.js`：数据模型工厂函数，创建空单元格、空行、初始行以及示例数据。

#### `js/services/` 服务层

- `storage.js`：统一封装 `localStorage` 读写操作，提供数据集列表、备注、用户颜色、表格尺寸、底色、悬浮框布局等持久化接口。
- `modal.js`：管理所有通用弹窗的打开/关闭、提示/确认、非法输入提示、全部获取提示，并提供 Toast 轻提示功能。

#### `js/features/` 功能层

##### `data/` 数据管理

- `dataset-manager.js`：数据集的新建、重命名、删除、切换；保存/加载数据；默认数据集保护逻辑（只增不减）；更新锁定状态 UI。
- `dataset-remark.js`：数据集级备注的显示与编辑，默认/示例数据集备注固定只读，普通数据集可编辑。
- `import-export.js`：数据导出（ZIP/JSON）与导入（ZIP/JSON），处理图片打包/还原、重名冲突。
- `default-loader.js`：从 `data/data.json` 异步加载默认数据集，将图片文件名转换为 Data URL，显示加载进度。

##### `table/` 表格相关

- `table-renderer.js`：渲染主表格的两个部分（强攻~残暴、附术~效益），生成表头、数据行，应用状态颜色和奇偶行背景，管理单元格高亮。
- `row-filter.js`：行筛选弹窗的复选框渲染、全选/全不选、应用筛选、更新按钮文本。
- `stats.js`：统计面板的渲染，计算各词条组的总基质数、总实装、已获取、未获取，支持排序。
- `cell-tooltip.js`：表格顶部悬停提示栏的交互，显示当前单元格的详细信息。

##### `cell/` 单元格操作

- `cell-value.js`：数据输入面板的数值应用逻辑，包括实装基质获取、普通数值覆盖对比、二次确认。
- `cell-record.js`：录入面板的实装基质录入、撤减、清除；清空数据集和删除数据集的安全确认弹窗（倒计时+文字确认）。
- `history.js`：操作历史的记录、撤回、重做，更新按钮状态。

##### `preferences/` 设置与个性化

- `theme.js`：亮/暗主题切换，保存偏好，应用用户自定义颜色，同步表格底色。
- `table-style.js`：表格列宽、行高的读取/保存/应用，奇偶行底色的管理与实时更新。
- `color-preview.js`：设置弹窗中的颜色预览表格渲染、颜色编辑器（支持 HEX/RGB/RGBA/CMYK/HSLA）、颜色应用与撤销。

##### `note/` 备注功能

- `note.js`：单元格备注的读写、图片上传与管理、备注悬浮框的显示/隐藏/拖拽/调整大小/布局切换、图片查看器。

#### `js/events.js`

- 统一事件绑定入口，调用各个模块暴露的 `bindXXXEvents()` 方法，并绑定全局事件（面板折叠、设置导航、版本信息等）。

#### `js/main.js`

- 应用初始化流程：初始化 DOM 缓存、主题、数据、下拉框、表格样式、备注、事件绑定等。
- 提供布局管理方法 `App.layout.switchPanel` 和 `App.layout.switchLeftPanel`。
- 恢复右侧面板折叠状态，处理首次访问显示"关于"弹窗及默认数据集加载。

### `data/` 数据文件

- `data.json`：默认数据集的数据文件，包含 12 个提升项（行）的完整数据，每个单元格包含数值（`v`）、重复数（`t`）、获取数（`a`）以及备注（文本和图片文件名）。
- `data/default.js`：早期占位脚本，定义了 `DEFAULT_ROWS` 变量（当前为空数组），实际默认数据由 `default-loader.js` 从 `data.json` 加载。
- `data/images/`：存储默认数据集中备注引用的图片文件（PNG/WebP 格式），文件名与 `data.json` 中的引用一致。

## 模块化设计

项目采用 **IIFE + 全局命名空间 `App`** 的模块化方案，兼容 `file://` 协议，无需构建工具。

- **核心层** (`core/`)：提供常量、状态、DOM 缓存、工具函数、数据模型，被所有模块依赖。
- **服务层** (`services/`)：提供通用服务（存储、弹窗），供功能层调用。
- **功能层** (`features/`)：按业务领域划分为数据管理、表格、单元格操作、设置个性化、备注五个子目录，每个文件职责单一。
- **入口**：`events.js` 统一绑定事件，`main.js` 负责初始化。

## 主要功能

- 多数据集管理（新建、重命名、删除、切换）
- 数据录入、撤减、清除（带撤回/重做）
- 数值对比与智能建议
- 单元格备注（文本 + 图片，悬浮框展示）
- 行筛选显示
- 统计面板（可排序）
- 明暗主题切换
- 表格尺寸与底色自定义
- 状态颜色个性化（HEX/RGB/CMYK/HSLA 编辑）
- 数据导出/导入（ZIP 包含图片，JSON 纯数据）
- 默认数据集保护（只增不减）
