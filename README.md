# Endfield-Essence-Exhaustive

**EEE · 终末地基质穷举数据记录与统计工具**

> 为《明日方舟：终末地》设计的纯前端单页工具，用于记录、管理、统计“基质”数据。
> **零构建、零依赖、零后端** —— 一个文件夹拷贝走即可用。

**当前版本**：v0.9.17

---

## 快速开始

本项目通过 `fetch` 加载默认数据集与图片，**`file://` 协议会被浏览器拦截**，需本地 HTTP 服务器。

**推荐**：双击根目录的 `一键本地运行.bat`（自动用 Python 或 Node 启动服务器）。

**手动**：

```bash
python -m http.server 8000
# 或
npx http-server -p 8000
```

然后访问 <http://localhost:8000>。

> 数据存于 localStorage，图片存于 IndexedDB。无需安装依赖、无需构建。

## 能做什么

### 数据记录
- **840 格数据矩阵**：12 属性 × 14 系列技能 × 5 能力值
- 三种记录方式：数值输入 / 实装基质录入 / 撤减清除
- 数值智能对比：保留 / 替换建议，附计算依据

### 多数据集管理
- 新建 / 重命名 / 删除 / 切换
- 数据集级备注（≤ 550 字）
- **覆盖 / 合并**：冲突逐格处理，实时预览

### 备注系统
- 单元格文本 + 图片（单格 ≤ 10 张，单张 ≤ 1 MB）
- 悬浮框：拖拽 / 缩放 / 三种布局
- 应用内大图查看器（滚轮缩放）

### 统计信息面板（v0.9.17 重写）
- **左侧独立页**：从右侧边栏迁至左侧，左侧新增“空页面”入口
- **数据集切换**：独立于主界面当前数据集，仅用于统计查看
- **6 项总览**：
  - 单元格：总单元格 / 未填充 / 已填充（`完整 + 不完整` 复合显示）
  - 基质：总基质数 / 已获得 / 未获得
- **进度条**：单元格填充率（按获得比例加权，如 `1/2` 计 `0.5`）、基质获取率
- **维度明细**：能力值 / 属性 / 系列技能三维度切换，按未获取降序
- **缺口分析**：三交叉表合一（属性 × 系列技能 / 能力值 × 属性 / 能力值 × 系列技能）
  - 单一 `<table>` 组织，31 列对齐，左右顶部与底部对齐
  - 单元格按缺口数连续色阶 `hsl(120) → hsl(0)`（绿 → 黄 → 橙 → 红）
  - 底部色条标尺（两端标注 0 / 最大）
  - 每表独立归一化
  - 属性列头 / 行头缩写（攻 / 生 / 暴 …），鼠标悬浮显示全称
  - 能力值行头显示全名（敏捷 / 力量 / 意志 / 智识 / 主能力）
- **筛选**：三维度多条件交集，全选 / 清空
- **结果列表**：状态 / 数值 / 可获取地区 + 刷取方式（可展开）
- **详情悬浮窗**：各系列技能 6 项数据（总单元格 / 未填充 / 已填充 / 总基质 / 已获得 / 未获得）
- **右列宽度可拖动**（双击恢复默认），锁定 / 解锁

### 未获取基质统计
- **全局排名**：按刷取组合（3 能力值 + 1 属性/系列技能）统计缺口
- **显示模式切换**：未获取前 36 / 未获取后 36 / 全收集
- **刷取组合检索**：按地区 + 属性或系列技能 + 3 能力值组合精确检索
- **双击锁定**：双击条目 → 持续高亮 + 卡片下方“取消高亮”按钮
- **进度条**：每条显示完成度（红 <30% / 橙 30~70% / 绿 ≥70%）
- **地区筛选**：可只看关注地区，状态持久化
- **双色高亮**：悬停条目 → 未获取格红框、已获取格绿框，自动定位
- **变暗蒙版**：非高亮格弱化
- **缺口计数**：`t>0 且 a<t` 计 `(t-a)`，完全空白计 `1`

### 地区管理
- 内置 12 个地区（枢纽区、源石研究园、矿脉源区……）
- 每地区配置：8 属性 + 8 系列技能
- 支持新增 / 编辑 / 删除 / 恢复默认
- **悬停高亮**：悬停地区卡片 → 表格中该地区 320 格同步高亮
- **收集进度条**：卡片底部显示 `已完成 / 320`（X%）+ 分档着色

### 可获取地点悬浮窗
- 悬停未获取单元格 → 显示所有可获取该基质的地区
- 每地区两条刷取路径（选属性 / 选系列技能）
- **跟随筛选**；无结果回退全部
- **与备注悬浮窗同时出现**（v0.9.14）：两者以“主从定位”紧贴排列，**绝不重叠**

### 单元格备注悬浮窗
- 悬停有备注的单元格 → 显示备注文本与图片
- 支持拖拽 / 缩放 / 三种布局（文本上 / 图片上 / 横向）
- **与可获取地点悬浮窗同时出现**（v0.9.14）：紧贴主窗外侧布局

### 单元格键盘导航
- **方向键移动**：数据管理 / 录入面板激活时，用 ↑↓←→ 在单元格间移动选择
- **跨表连续**：↑↓ 可跨“第一部分 ↔ 第二部分”移动，**保持相对列位置**
- **左右不跨表**：←→ 仅在本部分内移动
- **自定义按键**：设置弹窗「表格设置」中可将 ↑↓←→ 改为任意按键（如 WASD）
- **自动滚动**：跨表时自动滚动到目标表格的可视区域
- **不干扰输入**：焦点在输入框内时方向键走原生行为

### 个性化
- **明暗主题**：跟随系统或手动切换，无闪烁
- **单元格状态颜色**：已拥有 / 未获取 / 部分获取 / 全部获取
- **界面颜色**：所有 CSS 颜色变量可调，含主界面预览
- **方案管理**：界面方案与单元格方案独立保存、导入导出

### 性能与交互
- **高亮索引缓存**：320 格高亮从 320 次 DOM 查询降为 O(1)

## 数据模型

每个单元格：

| 字段 | 含义 | 约束 |
|------|------|------|
| `v` | 数值 | 空串 = 无数值 |
| `t` | 实装重复数 | ≥ 0 |
| `a` | 已获取数 | `0 ≤ a ≤ t`（自动夹紧） |
| `note` | `{ text, images[] }` | images 为 IndexedDB ID |

**状态**：

- `t=0, v≠''` → has-value
- `t>0, a=0` → 未获取
- `0 < a < t` → 部分获取
- `a = t` → 全部获取

**刷取机制**：每地区提供 8 属性 + 8 系列技能；每次刷取选 3 能力值 + 1 属性或 1 系列技能，从 24 种候选中随机得 3。

## 键盘快捷键

| 快捷键 | 行为 |
|--------|------|
| `↑` / `↓` / `←` / `→` | 移动单元格选择（**可在设置中自定义**） |
| `Ctrl/Cmd + Z` | 撤回 |
| `Ctrl/Cmd + Shift + Z` | 重做 |
| `Ctrl/Cmd + Y` | 重做 |
| `Escape` | 关闭最上层弹窗 |

**方向键导航规则**：

- 仅在「数据管理」或「录入面板」激活时生效
- ↑↓ **跨表连续**：第一部分末行 ↓ → 第二部分首行（相对列位置不变）
- ←→ **不跨表**：第一部分最右列 → 不跳到第二部分
- 焦点在 `input` / `textarea` / `contenteditable` 内时，方向键走原生行为
- 焦点在 `select` 上时，方向键走导航（覆盖 select 原生行为）
- 有弹窗打开时不触发
- 行筛选后，↑↓ 只在可见行之间移动

## 常见问题

### 打开后数据没加载？

**必须通过 HTTP 服务器访问**（`file://` 下 `fetch` 被拦截）。使用 `一键本地运行.bat`。

### 数据存在哪里？

- **数据集 / 设置 / 备注文本 / 地区配置**：`localStorage`
- **备注图片**：`IndexedDB`（`eee_image_db`）
- **会话标记**：`sessionStorage`

按 **origin** 隔离——`localhost:8000` 与 `localhost:3000` **不互通**。

### 换电脑 / 换浏览器怎么迁移？

用「导出」生成 ZIP（含图片），新环境「导入」即可。JSON **不含图片二进制**。

> 地区配置、地区筛选不随数据集导出，需重新配置。

### 默认数据集被我改乱了？

点「重置同步」重新拉取 `data/data.json`。**重置后用户添加的数据会丢失**。

### 数据丢了怎么办？

工具不做云端备份。建议：
- 定期「导出」ZIP 备份
- 避免浏览器“清除浏览数据”
- 用「清除缓存」时，弹窗会展示将删除的清单

### 未获取统计怎么算的？

每组合 24 格（3 能力值 × 8 属性/系列技能）。每格贡献：

| 状态 | 贡献 |
|------|------|
| `v='', t=0` | +1 |
| `v≠'', t=0` | 0 |
| `t>0, a=t` | 0 |
| `t>0, a<t` | `t - a` |

可通过三种模式查看：
- **未获取前 36**：缺口最多的组合
- **未获取后 36**：缺口最少（接近刷满）的组合
- **全收集**：缺口 = 0 的组合

### 两个悬浮窗会互相遮挡吗？

**不会**（v0.9.14 起）。悬停同时有备注且未完全获取的单元格时：
- **可获取地点悬浮窗**（主窗）先定位在鼠标附近
- **单元格备注悬浮窗**（从窗）紧贴主窗外侧布局，间距 8px

### 方向键怎么用？

在「数据管理」或「录入面板」激活时：

- **↑ / ↓**：在当前可见行之间移动；到达表格底部/顶部时**跨表**到另一个表格的对应列位置
- **← / →**：在当前部分的 70 列内移动；不跨表

> 想改键？打开「设置 → 表格设置 → 单元格键盘导航」，点击输入框后按任意键即可。

### 提交时被 husky 阻止？

说明暂存区有 lint 错误：

- **可自动修复的**（如 `let` → `const`）：husky 会自动 `eslint --fix` 后继续
- **不可自动修复的**（如 `var` 声明）：会**阻止提交**，需要手动修正

应急跳过：`git commit --no-verify`

### 升级后旧数据会丢失吗？

不会。`migration.js` 会按版本顺序执行迁移。

### 页面报 "Executing inline script violates"？

浏览器扩展或 Edge 内建功能注入的内联脚本被 CSP 拦下。**与项目代码无关，可忽略**。若担心，试试停用扩展或无痕模式验证。

### 首屏白屏很久？

已有加载遮罩 + 脚本 `defer`。若仍慢，通常是 GitHub Pages 网络延迟。

## 技术特性

- IIFE + 全局 `App` 命名空间；无构建工具
- 分层：核心 → 服务 → 功能 → 入口；`App.core.*` / `services.*` / `features.*` / `entry.*`
- **命名空间冻结**：`App.core` / `App.services` 运行时只读，防止误替换模块引用
- XSS 防护：`innerHTML` 前统一 `escapeHtml`
- CSP 严格化：`script-src 'self'`
- 图片隔离：IndexedDB 与 localStorage 分离
- 全局错误边界 + 数据迁移 + 弹窗 A11y
- 竞态防护 + 高亮索引缓存 + 统计计算缓存 + **单元格查询复用**
- 悬浮窗主从定位（v0.9.14）：从窗围绕主窗实际矩形布局
- 键盘导航（v0.9.15）：跨表连续 + 自定义按键 + 焦点释放
- 统计面板（v0.9.17）：左侧独立页 + 三交叉表 + 连续色阶 + 详情悬浮窗
