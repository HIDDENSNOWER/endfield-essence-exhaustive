# Endfield-Essence-Exhaustive

**EEE · 终末地基质穷举数据记录与统计工具**

> 为《明日方舟：终末地》设计的纯前端单页工具，用于记录、管理、统计"基质"数据。
> **零构建、零依赖、零后端** —— 一个文件夹拷贝走即可用。

**当前版本**：v0.9.13

---

## 快速开始

本项目通过 `fetch` 加载默认数据集与图片，**`file://` 协议会被浏览器拦截**，需本地 HTTP 服务器。

**推荐**：双击根目录的 `一键本地运行.bat`（自动用 Python 或 Node 启动服务器）。

**手动**：

```bash
python -m http.server 8000
# 或
npx http-server -p 8000
```

然后访问 <http://localhost:8000>。

> 数据存于 localStorage，图片存于 IndexedDB。无需安装依赖、无需构建。

## 能做什么

### 数据记录
- **840 格数据矩阵**：12 属性 × 14 系列技能 × 5 能力值
- 三种记录方式：数值输入 / 实装基质录入 / 撤减清除
- 数值智能对比：保留 / 替换建议，附计算依据

### 多数据集管理
- 新建 / 重命名 / 删除 / 切换
- 数据集级备注（≤ 550 字）
- **覆盖 / 合并**：冲突逐格处理，实时预览

### 备注系统
- 单元格文本 + 图片（单格 ≤ 10 张，单张 ≤ 1 MB）
- 悬浮框：拖拽 / 缩放 / 三种布局
- 应用内大图查看器（滚轮缩放）

### 未获取基质统计（v0.9.13 增强）
- **全局排名**：按刷取组合（3 能力值 + 1 属性/系列技能）统计缺口
- **显示模式切换**（v0.9.13）：未获取前 36 / 未获取后 36 / 全收集
- **刷取组合检索**（v0.9.13）：按地区 + 属性或系列技能 + 3 能力值组合精确检索
- **双击锁定**（v0.9.13）：双击条目 → 持续高亮 + 卡片下方"取消高亮"按钮
- **进度条**：每条显示完成度（红 <30% / 橙 30~70% / 绿 ≥70%）
- **地区筛选**：可只看关注地区，状态持久化
- **双色高亮**：悬停条目 → 未获取格红框、已获取格绿框，自动定位
- **变暗蒙版**：非高亮格弱化
- **缺口计数**：`t>0 且 a<t` 计 `(t-a)`，完全空白计 `1`

### 地区管理
- 内置 12 个地区（枢纽区、源石研究园、矿脉源区……）
- 每地区配置：8 属性 + 8 系列技能
- 支持新增 / 编辑 / 删除 / 恢复默认
- **悬停高亮**：悬停地区卡片 → 表格中该地区 320 格同步高亮
- **收集进度条**：卡片底部显示 `已完成 / 320`（X%）+ 分档着色

### 可获取地点悬浮窗
- 悬停未获取单元格 → 显示所有可获取该基质的地区
- 每地区两条刷取路径（选属性 / 选系列技能）
- **跟随筛选**；无结果回退全部
- 与备注并列，位置自动错开

### 个性化
- **明暗主题**：跟随系统或手动切换，无闪烁
- **单元格状态颜色**：已拥有 / 未获取 / 部分获取 / 全部获取
- **界面颜色**：所有 CSS 颜色变量可调，含主界面预览
- **方案管理**：界面方案与单元格方案独立保存、导入导出

## 数据模型

每个单元格：

| 字段 | 含义 | 约束 |
|------|------|------|
| `v` | 数值 | 空串 = 无数值 |
| `t` | 实装重复数 | ≥ 0 |
| `a` | 已获取数 | `0 ≤ a ≤ t`（自动夹紧） |
| `note` | `{ text, images[] }` | images 为 IndexedDB ID |

**状态**：

- `t=0, v≠''` → has-value
- `t>0, a=0` → 未获取
- `0 < a < t` → 部分获取
- `a = t` → 全部获取

**刷取机制**：每地区提供 8 属性 + 8 系列技能；每次刷取选 3 能力值 + 1 属性或 1 系列技能，从 24 种候选中随机得 3。

## 常见问题

### 打开后数据没加载？

**必须通过 HTTP 服务器访问**（`file://` 下 `fetch` 被拦截）。使用 `一键本地运行.bat`。

### 数据存在哪里？

- **数据集 / 设置 / 备注文本 / 地区配置**：`localStorage`
- **备注图片**：`IndexedDB`（`eee_image_db`）
- **会话标记**：`sessionStorage`

按 **origin** 隔离——`localhost:8000` 与 `localhost:3000` **不互通**。

### 换电脑 / 换浏览器怎么迁移？

用「导出」生成 ZIP（含图片），新环境「导入」即可。JSON **不含图片二进制**。

> 地区配置、地区筛选不随数据集导出，需重新配置。

### 默认数据集被我改乱了？

点「重置同步」重新拉取 `data/data.json`。**重置后用户添加的数据会丢失**。

### 数据丢了怎么办？

工具不做云端备份。建议：
- 定期「导出」ZIP 备份
- 避免浏览器"清除浏览数据"
- 用「清除缓存」时，弹窗会展示将删除的清单

### 未获取统计怎么算的？

每组合 24 格（3 能力值 × 8 属性/系列技能）。每格贡献：

| 状态 | 贡献 |
|------|------|
| `v='', t=0` | +1 |
| `v≠'', t=0` | 0 |
| `t>0, a=t` | 0 |
| `t>0, a<t` | `t - a` |

v0.9.13 起，可通过三种模式查看：
- **未获取前 36**：缺口最多的组合
- **未获取后 36**：缺口最少（接近刷满）的组合
- **全收集**：缺口 = 0 的组合

### 检索面板怎么用？

- **地区**：下拉选择目标地区
- **类型**：属性 / 系列技能
- **目标**：具体属性名或系列技能名
- **能力值**：3 能力值组合

点「检索」显示结果卡片，含进度条与未获取数。悬停/双击卡片可高亮表格对应格。

### 双击锁定是什么？

双击未获取统计的任一条目 → 表格对应单元格持续高亮（不会因移出而消失）。条目下方会出现「取消高亮」按钮。切换面板 / 重新渲染列表 / 再次检索时自动解除。

### 升级后旧数据会丢失吗？

不会。`migration.js` 会按版本顺序执行迁移。

### 页面报 "Executing inline script violates"？

浏览器缓存问题。`Ctrl+Shift+R` 硬刷新，或清浏览器缓存。

### 首屏白屏很久？

v0.9.10 起已有加载遮罩 + 脚本 `defer`。若仍慢，通常是 GitHub Pages 网络延迟。

## 技术特性

- IIFE + 全局 `App` 命名空间；无构建工具
- 分层：核心 → 服务 → 功能 → 入口；`App.core.*` / `services.*` / `features.*` / `entry.*`
- XSS 防护：`innerHTML` 前统一 `escapeHtml`
- CSP 严格化：`script-src 'self'`
- 图片隔离：IndexedDB 与 localStorage 分离
- 全局错误边界 + 数据迁移 + 弹窗 A11y
- 竞态防护 + 高亮索引缓存 + 统计计算缓存
