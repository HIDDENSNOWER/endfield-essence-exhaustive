# Endfield-Essence-Exhaustive (EEE)

**终末地基质穷举数据记录与统计工具**  
Ver.0.6.0 ("再访基地"更新)

一个用于记录、管理和统计《明日方舟：终末地》中"基质"数据的**纯前端工具**，零构建、随手可用。  
支持多数据集管理、数据覆盖/合并、导入导出、备注与图片、颜色个性化、明暗主题、清除缓存等功能。

---

## 快速开始

本项目为纯静态页面，但默认数据集与备注图片通过 `fetch` 异步加载，**`file://` 协议下会被浏览器跨源策略拦截**，因此需通过本地 HTTP 服务器运行：

- **推荐**：双击根目录的 `一键本地运行.bat`（自动用 Python 或 Node 的 http-server 启动，并打开 `http://localhost:8000`）
- 或手动执行任一命令：
  ```bash
  python -m http.server 8000        # Python
  npx http-server -p 8000           # Node
  ```
  然后浏览器访问 `http://localhost:8000`

> 无需安装任何依赖、无需构建、无需数据库，所有数据保存在浏览器 `localStorage` 中。

## 数据模型

表格固定 **14 个词条组（强攻~效益）× 5 个副属性 = 70 列**，分为两部分渲染（强攻~残暴、附术~效益）；共有 **12 个提升项（行）**。

每个单元格为如下结构：

| 字段 | 含义 |
|------|------|
| `v` | 数值（普通数值，或实装基质的属性值） |
| `t` | 重复数（≥0，实装基质的重复次数） |
| `a` | 已获取数（`0 ≤ a ≤ t`，归一化时自动夹紧） |
| `note` | `{ text: 备注文本, images: 图片数组 }` |

单元格状态依据 `t` / `a` 判定：**未获取**（`a=0`）、**部分获取**（`0<a<t`）、**全部获取**（`a=t`），以及仅含数值时的 **has-value** 态。

## 主要功能

- **多数据集管理**：新建、重命名、删除、切换、数据集级备注；数据集名做保留键校验，避免覆盖系统存储
- **数据集覆盖 / 合并**：勾选多个独立数据集进行合并，支持「覆盖 / 智能合并 / 保留现有」三种策略；冲突单元格**逐格选择处理方式**，策略结果**实时预览**，点击冲突行查看完整信息（备注全文 + 图片清单）
- **数据记录**：录入、撤减、清除（带撤回/重做，切换/清空/导入/合并后自动重置历史）
- **数值对比与智能建议**：输入三位数时与旧值对比并给出建议
- **单元格备注**：文本 + 图片（悬浮框拖拽/缩放/布局切换、应用内大图查看）
- **行筛选**、**统计面板（可排序）**
- **明暗主题**（跟随系统 + 手动切换，无 FOUC 闪烁）
- **表格尺寸 / 底色自定义**、**状态颜色个性化**（HEX/RGB/CMYK/HSLA 编辑，越界值自动钳制）
- **数据导入 / 导出**：ZIP（含图片）与 JSON；导入带大小限制、缺失图片提示、重名冲突处理
- **默认数据集保护**（只增不减，刷新不覆盖用户数据）
- **清除浏览器缓存**：点击后展示当前已保存的全部数据内容，确认后清理并无刷新初始化 `localStorage`/`sessionStorage`/Cache API

## 模块化设计

项目采用 **IIFE + 全局命名空间 `App`** 的模块化方案，兼容 `file://` 直接打开（须由本地 HTTP 服务器承载），无构建工具、无运行依赖。

- **核心层** (`core/`)：常量、状态、DOM 缓存、工具函数、数据模型，被所有模块依赖。
- **服务层** (`services/`)：存储、弹窗等通用服务，供功能层调用。
- **功能层** (`features/`)：按业务领域分为 data、table、cell、preferences、note 五个子目录，每个文件职责单一。
- **入口**：`events.js` 统一绑定各模块 `bindXXXEvents()`，`main.js` 负责按序初始化。

### 分层说明

| 层 | 目录 | 职责 |
|----|------|------|
| 核心层 | `js/core/` | 常量、状态、DOM 缓存、工具函数、数据模型 |
| 服务层 | `js/services/` | 存储、弹窗管理（含 Toast） |
| 功能层 | `js/features/` | 数据管理 / 表格 / 单元格操作 / 设置个性化 / 备注 |

## 数据安全与可靠性

- 所有数据存储于浏览器 `localStorage`，按数据集名隔离；数据集名做了**保留键校验**（拒绝 `smarttable_*` 前缀），防止覆盖系统存储键
- 默认数据集采用**只增不减**保护：以初始数据为基准，禁止减少或清除；切换/清空/导入/合并后自动重置操作历史，防止跨数据集误撤回
- 写入失败（如存储空间不足）会**明确提示**，避免"假保存"；图片上传有大小/数量限制
- 导入 ZIP 有大小限制与缺失图片提示，导出对损坏数据容错
- 弹窗、下拉框、备注、合并预览等处对用户输入做 **HTML 转义**，防范注入
